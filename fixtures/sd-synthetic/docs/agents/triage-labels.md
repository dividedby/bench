# Triage labels

Local-markdown tracker. Each canonical triage role maps to a literal label string
added to an issue file's `labels:` frontmatter.

| Role | Label |
|---|---|
| needs evaluation | `needs-triage` |
| waiting on reporter | `waiting-on-reporter` |
| ready for AFK agent | `ready-for-agent` |
| ready for human | `ready-for-human` |
| won't fix | `wontfix` |
