# CONTEXT — linksnip web UI

The customer-facing web app for `linksnip`, a URL-shortening service. This fixture
contains the **Settings** page only, in a deliberately generic, unstyled state.

## Stack
Vanilla HTML/CSS/JS (no framework, no build step). `index.html` + `styles.css` + `app.js`.

## Brand
`linksnip` is a developer-facing tool: terse, fast, technical. Audience is engineers who
mint short links via API and occasionally tweak settings in the browser. It should feel
precise and confident — not playful, not corporate-generic.

## Current state
`styles.css` is a placeholder baseline with no design point of view. The Settings page
works but looks like an unstyled form.
